## YT 下载器 v1.4.1 — 首个公开发布版本

基于 yt-dlp 的 Windows 图形界面，把一长串命令行参数变成点几下就能完成。适合「同一个视频要下多个版本、想本地归档」的场景。

### 核心能力

- **格式完全可控**：视频流和音频流分两张表列出来，点哪行下哪个，不做黑盒「智能选择」
- **同视频多版本共存**：文件名自动带 `1080p.VP9` 这类标签，4K/1080p、H.264/VP9/AV1 互不覆盖
- **容器自动选对**：按 yt-dlp 的真实规则预测 mp4 / webm / mkv，跨族自动落 mkv，不会下出「播放器黑屏」的错盒文件
- **附加项可选**：封面 / 元数据 / 章节 / 字幕，按容器能力自动降级（mkv 全支持，webm 只留元数据）
- **下载历史去重**：同一个「视频 + 视频格式 + 音频格式 + 容器」组合下过就提示，换画质不会互相顶掉
- **下载历史可追溯**：记录下过什么，双击直接打开文件

### 这个版本做了什么

**使用体验**
- 进度分三段显示：`① 视频流 → ② 音频流 → ③ 封装`，下载标签会显示当前格式 ID（如「正在下载视频流（313）」）
- 状态栏新增「定位文件」（资源管理器里直接选中）与「复制路径」
- 下载前自动检查保存目录可写、剩余空间够不够（按估算 ×2 预留合并空间）
- 只允许开一个窗口：重复双击会唤醒已打开的窗口
- 强制 mp4 但流是 VP9/Opus 时，摘要会提示兼容性风险（只提示，不拦你）
- 引擎更新失败会自动回滚，不会把 yt-dlp 更成砖

**工程**
- 37 条参数化单元测试 + 44 项界面冒烟测试
- 打包写入 PE 版本资源，降低杀软误报
- 存档快照默认脱敏（家目录 → `%USERPROFILE%`，清空 cookies / 代理）
- 文档分层：`README.md` 面向使用者，`HANDOFF.md` 面向维护者（含 25 条设计决策与取舍）

```

```

### 已知限制

- 只针对 YouTube 调优过格式逻辑，其他站点可能异常
- 字幕接口容易触发限流（HTTP 429），所以字幕默认关闭；开启后若失败，视频仍会正常下载并给出橙色提示
- 暂不支持批量队列与播放列表整包下载，计划在后续版本
- 首次启动约 1 秒无响应（Windows 平台初始化），期间会显示启动图
